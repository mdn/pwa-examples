PWA install demos

This page lists the examples we have available to demonstrate usage of the available methods for installing a PWA directly from a webpage, namely the Navigator.install() method and the <install> element.

  1. Install an app from its landing page via the Navigator.install() method
  2. Install an app from its landing page via the <install> element
  3. Install multiple apps from a catalog page using the Navigator.install() method
  4. Install multiple apps from a catalog page using the <install> element
  5. Explore situations in which an <install> element can become invalid. Doesn't install an app.
